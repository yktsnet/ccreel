## picker の更新日を、暦の日ではなく24時間ごとに数える
id: 01
branch-slug: ago-by-24h
status: close
type: fix
対象: internal/picker/picker.go, internal/picker/picker_test.go, docs/guarantees.md, docs/usage.md, context/structure.md, README.md, README.en.md
内容: `Ago` の `*N` を、手元の暦の日ではなく更新からの経過時間で数える（`*0` は24時間以内、`*1` は24〜48時間前）。深夜0時を過ぎて終えた作業が、翌朝には `*0` に、その少し前の作業は `*1` に割れ、昨夜の作業をまとめて探せない。`Elapsed` も `*0` と同じく24時間以内の分に添える。
対象外: codeview の sessions 拡張（`examples/plugins/sessions.py` の FILTER_SCRIPT）の `*N` の絞り込み。別のリポなので、揃えるなら codeview 側で別の Issue にする。`show` / `outline` / `list` の JSON の時刻表記は変えない
仮定: 10日以上前を週（`2w`）で出す形と、その境目（240時間）は変えない。週は経過時間の日数（`経過時間 / 24h` の切り捨て）を7で割って出す
確認: `go vet ./...` と `go test ./...` が通る。`TestAgo` と `TestElapsed` が、下の「数え方」の表の値で通る
人が見るもの: 実機の `c` → history で、前日の夜〜深夜0時過ぎのセッションが `*0` に並び、`*0` で絞るとまとめて出ること

---

### 保証
- 新たに宣言する保証:
  - `Ago` は更新からの経過時間を24時間で割った切り捨てを日数とし、9日（216〜240時間前）までは `*` に続けて日数を、それより前は週（`2w`）を返す。日付をまたいでも、24時間以内なら `*0` になる
  - `Elapsed` は、24時間以内（`*0`）の分にだけ経過時間を返す。1分未満は `now`、60分未満は分（`12m`）、それ以上は時間（`23h`）で、24時間を過ぎたものは空にする
- 維持する保証:
  - `Line` は fzf の1行を「UUID・題・`@リポ #番号`・更新日・経過時間」のタブ区切りで作り、題より後ろは薄い色で出す
  - `*` を付けるのは1桁の日数だけで、`*1` が10日以上前の行に当たらない
  - 経過時間の列は fzf の `--nth` で絞り込みから外れ、`*1` や `12` が `*0` の行に当たらない
  - 時計のずれで未来の時刻が来ても `*0`・`now` にする
- 廃止する保証:
  - `Ago` が端末のローカル時刻の日付で日数を数えること（`TestAgo` の「日付をまたいだ1時間前は昨日」のケースを書き換える）

### 数え方

| 更新からの経過 | `Ago` | `Elapsed` |
|---|---|---|
| 30秒 | `*0` | `now` |
| 1時間（日付をまたぐ） | `*0` | `1h` |
| 23時間59分 | `*0` | `23h` |
| 24時間ちょうど | `*1` | （空） |
| 47時間 | `*1` | （空） |
| 9日と23時間 | `*9` | （空） |
| 10日 | `1w` | （空） |
| 未来（時計のずれ） | `*0` | `now` |

### internal/picker/picker.go
- `Ago`: 暦の日の差ではなく `now.Sub(t)` から日数を出す。負は0にする。`Ago` と `Elapsed` の上のコメントを、24時間ごとに数える理由（日付をまたいだ作業を一続きに探せる）に書き直す
- `Elapsed`: 判定は `Ago(t, now) == "*0"` のままでよい。コメントの「今日」を「24時間以内」に直す
- fzf の `--header` の `*0 (today) *1 …` を、24時間の意味が伝わる表記（例: `*0 (last 24h) *1 …`）に直す
- `cmd/ccreel/main.go` の preview は `Ago` と時刻（`15:04`）を並べているだけなので、触らない

### internal/picker/picker_test.go
- `TestAgo` と `TestElapsed` を上の表のケースで書き直す。日付をまたいだ24時間以内が `*0` になるケースと、24時間ちょうどが `*1` になる境目のケースを必ず入れる
